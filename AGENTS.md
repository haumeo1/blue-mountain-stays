# Agent guide

This repository is a vanilla JavaScript vacation-rental manager for one property, deployed on Vercel.
Read [`docs/architecture.md`](docs/architecture.md) before changing code.

## Roles

- Opus writes the code. GPT reviews, installs dependencies, and runs tests.
- Keep changes incremental and scoped to the current phase.

## Hard rules

- Browser code (`src/`) must never import `server/`, `api/`, Node built-ins, or server-only packages (`stripe`, `resend`, `pg`), and must never read `process.env`.
- `api/` files are thin Vercel route handlers. Shared logic lives in `server/` (never `api/_*`).
- `server/` modules import only other `server/` modules or packages.
- Only `dist/` is served. It is generated by `npm run build` from an explicit allow-list in `public/` plus bundles of `src/`. Do not hand-edit `dist/`.
- Supabase is authoritative for bookings, availability, auth, and storage. Stripe is authoritative for payment state, and only via verified webhooks.
- Never trust browser-provided prices, totals, or payment status.
- `DEMO_MODE` is local-only. Deployed environments must fail closed (disable booking with a clear message), never fall back to local simulation.
- Do not persist guest PII or confirmations in browser storage.
- Never read or commit `.env`, `.env.local`, or other secrets. Only `.env.example` is tracked.
- Do not edit `package-lock.json` by hand.

## Commands (Node 22)

- `npm run check` — syntax checks for every script plus import-boundary checks
- `npm test` — unit tests in `tests/`
- `npm run build` — produce `dist/` and scan it for leaked server-only env values
- `npm run dev` — build, then serve `dist/` and `api/` on 127.0.0.1

In Conductor, prefix commands with `./scripts/with-node.sh`.
